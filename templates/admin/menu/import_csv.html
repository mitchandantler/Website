Upload a CSV file to create or update Menu Items in bulk. Columns:

  • category (required) — must match an existing Menu Category name exactly (e.g. "All Day Menu", "Little Ones", "Coffee and Frappes", "Cold Beverages", "Cold Drinks")
  • name (required) — the menu item's name
  • price (required) — e.g. 12.50
  • description (optional)
  • dietary_tags (optional) — comma-separated, e.g. "Vegan, Gluten Free"
  • is_available (optional) — true/false, defaults to true
  • display_order (optional) — number controlling order within the category, defaults to 0

If a row's category + name matches an existing item, that item is updated. Otherwise a new item is created. It's safe to re-upload the same file after fixing a typo — nothing will be duplicated.

Nothing goes live automatically. Every item this import creates or updates is marked "unapproved" and stays hidden from the public Menu page until you review it here (double-check the price, description, and especially the dietary tags) and approve it — filter by "Is approved: No" after importing, then select the rows and use the "Approve selected menu items" action.
